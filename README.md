# React Modularity Assignment 🎨

This project is a simple **React application** designed to practice **component modularity** using **default and named imports/exports**.  
It includes a **dynamic name input feature**, styled components, and structured UI.

---

## 🚀 **Project Overview**
This React app consists of multiple modular components:
- **Header** and **Footer** (default exports)
- **ContentA** and **ContentB** (named exports)
- **SharedComponents** (contains a reusable `Button` component)
- **Dynamic User Input** (Users can enter their name, and it updates dynamically)
